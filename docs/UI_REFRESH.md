**دامنه:** `DashboardScreen.kt` · `strings.xml` هر دو زبان.

**حکم این دور:** صفحهٔ خانه یک ستون بی‌پایان از یازده کارت بود و کاربر درست همین را «شلوغ و به‌هم‌ریخته» دید. ساختار عوض شد، نه فقط ترتیب: صفحه حالا یک سربرگ ثابت و یک ردیف سه‌تایی دارد و هر تب فقط یک کار می‌کند.
